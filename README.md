
# BorrowFi Dapp

BorrowFi is a modern, responsive decentralized finance (DeFi) application built with React, TypeScript, Vite, and Tailwind CSS. It allows users to interact with lending and borrowing smart contracts, manage collateral, and perform on-chain transactions with a beautiful UI.

## Features

- Connect your Ethereum wallet (MetaMask, WalletConnect, etc.)
- Add and withdraw collateral
- Borrow and repay tokens
- View your balances, loans, and collateral status
- Real-time notifications and transaction feedback
- Elegant, responsive UI with Tailwind CSS

## Technologies Used

- React & TypeScript
- Vite
- Tailwind CSS
- Viem (for blockchain interactions)
- Wagmi (for wallet and contract hooks)

## Getting Started

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open your browser at `http://localhost:5173`
4. Connect your wallet and start using BorrowFi!

## Folder Structure

- `src/components/` — UI components (StatusSection, CollateralSection, BorrowSection, RepaySection, Header)
- `src/contracts/` — Contract ABIs and addresses
- `src/utils/` — Utility functions
